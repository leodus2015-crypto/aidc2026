站点结构
────────
  主导航 5 页 + 404。
  ai-dc-design.html 通过 js/ai-dc-design-page.js 加载上述 8 个子页 iframe；
  ai-dc-room-layout.html 再通过 js/ai-dc-room-layout-page.js 加载四层示意与单层平面。

  Tab 顺序（ai-dc-design）：机房布局 | Token->Card->Power | 算力估算 | 机柜规划 | 产品协同 | 案例 A | 案例 B | Investment ROI
  默认 Tab：机房布局（roomLayout）。单层平面图（ai-dc-floor-detail.html）：
    · 左上角红色虚线标出一个 POD（含 EHU、风冷/液冷机房及电源区上半部；电源区与下方 POD 共用）
    · 配电功能区 420 m² 标注于虚框内电源区上半部
    · 图下 POD 布局说明（12 POD / 320 机柜 / POD 定义）；embed 模式下图面等比缩放防裁切
  About US：代码量 20,850 行、三周期 Token 累计；scripts/merge-usage-events-csv.py 增量合并 CSV

说明
────
  与本目录源码一致；解压即用或与服务器 wwwroot 同步。
  全站采用方案 B（单 HTML + i18n/*.json）；英文通过 ?lang=en 或页内语言切换。
  Light / Dark 与语言维度分离；主题存入 aidc-theme，并通过 postMessage 同步嵌套 iframe。
  ai-dc-layout.html 使用页内 EN{}，并通过 AidcLocaleBridge 与父页同步语言。
  3D 案例默认配置见 data/dc3d-case-a.defaults.json / dc3d-case-b.defaults.json；
  云端配置键 dc3d.case_a / dc3d.case_b（MySQL app_config JSON，非逐字段建表）。
  embed 模式：子页 URL 加 ?embed=1，样式见 css/embed.css、js/embed-mode.js；
  embed 下保留精简顶栏（俯视/水平/透视/Cooling），隐藏 Logo 与主题切换。
  已删除的旧 HTML 入口由 deploy/nginx-static-cache.conf 提供 301 兼容跳转。
  站点状态：status.html（内部页；About US 头像悬停 2s 入口）+ deploy/ANALYTICS.md。
  云端 MySQL：部署后执行 python3 scripts/migrate.py；仅当种子即产品口径时再 seed-config.py。

部署（本机最新 → 腾讯云部署版；GitHub 仅归档）
────────────────────────────────────
  cp deploy.env.example deploy.env   # 填写 SSH，勿提交
  ./scripts/deploy.sh --sync-only --no-commit              # 正式：rsync --delete
  ./scripts/deploy.sh --full-reset --sync-only --no-commit # 首次或残留过多时
  ./scripts/deploy.sh --push-only                          # 验收后 push 开源归档
  部署后（服务器项目根，用该机 .env）：
    python3 scripts/migrate.py
    # 仅当允许覆盖线上 roi.* / dc3d.* 时：python3 scripts/seed-config.py
    ./start-api-prod.sh
    # 确认 .env：ADMIN_TOKEN=<强随机值>、DATABASE_*、ANALYTICS_LOG=…
